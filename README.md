## Publish on GitHub Pages

1. Create a **public** repository named `upwork-portfolio` on GitHub.
2. Upload all files in this directory **to the repository root** (not the enclosing directory).
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your public portfolio will typically be at `https://YOUR-USERNAME.github.io/upwork-portfolio/` after deployment.

The HTML prototypes are original demonstration interfaces; they are not Figma source files, and no real bookings, orders, or customer-support tickets are processed.
